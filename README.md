# DATA ADVENTURE – HÀNH TRÌNH CHINH PHỤC DỮ LIỆU
## BÀI 13: BIỂU DIỄN DỮ LIỆU (TIN HỌC PHỔ THÔNG)

Ứng dụng học tập và kiểm tra đánh giá tương tác môn Tin học (Bài 13: Biểu diễn dữ liệu), được xây dựng trên nền tảng **React 19 + Vite + Tailwind CSS** và kết nối cơ sở dữ liệu thời gian thực **Google Sheets thông qua Google Apps Script**.

---

### CẤU TRÚC CHÍNH CỦA ỨNG DỤNG
1. **VẬN DỤNG – CHINH PHỤC 5 THỬ THÁCH (Thang điểm 100)**:
   - **Thử thách 1 (20đ)**: Nhà thông thái dữ liệu (Chọn 1 đáp án - Kiểu xâu kí tự `Computer`).
   - **Thử thách 2 (20đ)**: Giải mã phép toán (Chọn nhiều đáp án - Phép toán logic AND, OR, NOT).
   - **Thử thách 3 (20đ)**: Điền đúng vị trí (Kéo thả chữ vào ô trống - Phân biệt bản chất Biến `THAY ĐỔI` và Hằng `KHÔNG ĐỔI`).
   - **Thử thách 4 (20đ)**: Hoàn thiện biểu thức (Điền biểu thức toán học - Góc quay đa giác đều `360/n`).
   - **Thử thách 5 (20đ)**: Kết nối tri thức (Ghép đôi 3 nhóm phép toán với kiểu dữ liệu tương ứng).
2. **BẢNG XẾP HẠNG TOÀN QUỐC**:
   - Vinh danh TOP 10, TOP 50 và hiển thị vị trí thứ hạng của học sinh trên toàn quốc theo thời gian thực.
3. **HỒ SƠ CÁ NHÂN & HUY HIỆU**:
   - Theo dõi kết quả từng câu, độ chính xác và danh hiệu mở khóa.
4. **KHU VỰC QUẢN TRỊ GIÁO VIÊN**:
   - Quản lý và chỉnh sửa nội dung 5 câu hỏi Vận dụng, xem trước câu hỏi, khôi phục mặc định.
   - Báo cáo dữ liệu học sinh, xuất file CSV.
   - Đổi mật khẩu giáo viên (mặc định: `2026`).

---

### HƯỚNG DẪN CHẠY DỰ ÁN CỤC BỘ
1. Cài đặt thư viện:
   ```bash
   npm install
   ```
2. Khởi chạy ứng dụng:
   ```bash
   npm run dev
   ```
3. Xây dựng bản phân phối (Build):
   ```bash
   npm run build
   ```
